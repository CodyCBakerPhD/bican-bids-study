# bican-bids-study
A prototype showcase of a BIDS-Study organization of BICAN meta-collections on DANDI.

See [`scripts/README.md`](scripts/README.md) for a script that creates a Dandiset, sets its metadata from JSON, and adds owners from a TSV.

See [`scripts/README.md`](scripts/README.md#assemble_bids_studypy) for a script that assembles a BIDS-study Dandiset from existing DANDI assets, validates it, and uploads it.
